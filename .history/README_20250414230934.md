# Scientific-Python-Coursework-PHYS4038 - Stock Portfolio Management App

## Project Overview
This Stock Portfolio Management App was developed as part of my Master's project for the course **Scientific Programming in Python** (PHYS4038). The application allows users to manage their stock portfolios, track stock prices, and perform basic financial analysis, including risk assessment and portfolio management.

## Features
- **User Authentication**: Sign up and login functionality.
- **Portfolio Management**: Add and remove stocks from the portfolio, view portfolio details (ticker, quantity, buy price, current price).
- **Stock Risk Analysis**: Calculate the risk associated with the portfolio and individual stocks using standard deviation and beta values.
- **Financial Analysis**: Generate plots and statistical analysis such as daily returns distribution, standard deviation comparison, and more.
- **Database Integration**: Store and retrieve portfolio data from an SQLite database.

## Key Components
1. **Dashboard**: The main interface where users can see their portfolio, add or remove stocks, and view portfolio risk.
2. **Stock Management**: Allows users to add stocks with details like ticker symbol, quantity, and buy price. Users can also delete stocks.
3. **Risk and Financial Analysis**: Perform risk analysis and display stock metrics such as standard deviation, beta, and portfolio performance.
4. **Database (SQLite)**: A simple database system to store user credentials and portfolio data persistently.

## Technologies Used
- **Python**: The core language used to build the application.
- **Tkinter**: A Python library for building graphical user interfaces.
- **SQLite**: A lightweight database used to store user information and portfolio data.
- **yfinance**: A library to fetch live stock data.
- **Matplotlib**: For creating visual plots and charts.

## How to Run
1. Ensure Python 3.x is installed on your system.
2. Install the required Python libraries using the `requirements.txt` file:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the `StockPortfolioApp` script:
   ```bash
   python stock_portfolio_app.py
   ```
   This will start the application and open the user interface.

## Conclusion
This app demonstrates the use of Python for scientific programming, applying concepts like data analysis, risk assessment, and visualization to a real-world application—stock portfolio management. The app can be extended with more advanced features like real-time price tracking, optimization of portfolio, and integration with additional financial data sources.
